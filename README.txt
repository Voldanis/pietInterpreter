# README: Piet Interpreter

Этот проект представляет собой интерпретатор языка программирования Piet.

## Установка зависимостей
Перед запуском убедитесь, что у вас установлены все необходимые библиотеки:
pip install PyQt6 Pillow numpy

## 1. Запуск консольного интерпретатора (piet.py)
Этот скрипт отвечает за основную логику интерпретации кода Piet.
Используется для прямого выполнения программы Piet.

Команда для запуска:
python piet.py <путь_к_файлу_программы>

## 2. Запуск графического интерфейса (step_by_step_piet.py)
Графический интерпретатор позволяет пошагово исполнять код Piet с визуализацией состояния стека и указателя.

Команда для запуска:
python step_by_step_piet.py <путь_к_изображению>

## 3. Запуск тестов (tests.py)
Для проверки корректности работы логики интерпретатора используйте стандартный модуль `unittest`.

Команда для запуска:
python -m unittest tests.py

## 4. Описание вспомогательных файлов
- normalizer.py: Содержит логику нормализации входных изображений (масштабирование, поиск размеров коделов, проверка сетки).
- dop_funcs.py: Набор вспомогательных функций, включая проверку цветовой палитры изображения (поддерживаемые цвета Piet).

Эти файлы импортируются основными модулями автоматически, их запуск напрямую обычно не требуется.
